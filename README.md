# HR ANALYTICS DASHBOARD
Saat ini baru berisikan 1 proyek dashboard dengan menggunakan data Dummy yang berasal dari Kaggle

## HR 1 POWER BI - EXCEL
Merupakan dashboard interaktif Power BI yang datanya connect dari Excel.
Kekurangan dari data saat ini adalah:
1. tidak ada data salary
2. merupakan data snapshot sehingga kalender tidak mampu membandingkan metrik dengan bulan/tahun lalu dengan baik
3. tidak ada level Pendidikan dan level pekerjaan, sehingga tidak bisa dibuat group by education dan job satisfication.
